CL-RL-2026-002:バーストカウントの一時的な過剰消費
症状:短時間(100ms以内)に多数のリクエストを送信すると、X-RateLimit-Remaining
の減少量が実際の消費数より多くカウントされる場合があります。最大で実際の1.2倍程度まで
多めに減少します。
影響範囲:全プラン。特にバッチエンドポイントを高頻度で呼び出すケース。
回避策:
クライアント側で同時実行数を制御し、100ms以内の集中送信を避けてください。X-RateLimi
t-Remainingではなく、自前のローカルカウンタで管理することも有効です。
