読み解きのポイント
保持期間の差は、監査要件の厳しさに応じてプランを選ぶ際の主要な判断材料になります。上位プ
ランほど長期保持を前提に設計されており、各プランでの具体的な保持日数は上の左側のグラフの
ラベルを参照してください。
APIレート制限については、バッチ処理や大規模連携を行う場合に上位プランの上限が必要になるケ
ースが多く、下位プランではピーク時に制限に達する事例が報告されています。各プランの上限値
は上の右側のグラフのラベルを参照してください。
