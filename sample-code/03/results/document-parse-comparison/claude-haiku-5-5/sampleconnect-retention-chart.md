# SampleConnect プラン別 運用指標ダッシュボード

本書は、営業・導入検討用に公開している運用指標の抜粋です。監査ログ保持期間とAPIレート制限は、プランによって桁が異なるためログスケールで表示しています。数値は各棒の上部ラベルに記載しており、本文中には具体値を繰り返し記載していません。

**図2の内容**

図タイトル：SampleConnect Platform プラン別 運用指標（2026年4月時点）

- 左：監査ログ保持期間（日）
  - 縦軸：保持日数（対数スケール、10¹〜10³）
  - Free：30日
  - Standard：90日
  - Enterprise：730日
- 右：APIレート制限（req/sec）
  - 縦軸：リクエスト毎秒（対数スケール、10¹〜10³）
  - Free：10 req/sec
  - Standard：100 req/sec
  - Enterprise：1,000 req/sec

図2. 左：監査ログ保持期間の比較。右：APIレート制限の比較。どちらも縦軸は対数スケールで、ラベルにプランごとの値が記載されています。

## 読み解きのポイント

保持期間の差は、監査要件の厳しさに応じてプランを選ぶ際の主要な判断材料になります。上位プランほど長期保持を前提に設計されており、各プランでの具体的な保持日数は上の左側のグラフのラベルを参照してください。

APIレート制限については、バッチ処理や大規模連携を行う場合に上位プランの上限が必要になるケースが多く、下位プランではピーク時に制限に達する事例が報告されています。各プランの上限値は上の右側のグラフのラベルを参照してください。

## 補足情報

本資料の数値は2026年4月時点のものです。正式な契約条件は別紙「プラン別機能比較」および「SampleConnect利用規約」に従います。
