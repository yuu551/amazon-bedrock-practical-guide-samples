# c10: 3月18日の障害でローリング再起動をどのような手順で実施したか、各ステップを順に説明してください

## fixed

- Latency: 4788.1 ms
- Citation count: 2
- Expected source hit: n/a

Answer:

3月18日の障害におけるローリング再起動は、以下の手順で実施されました。

1. 負荷分散層（ALB）でunhealthy判定となっているノードを切り離します。

2. 該当ノードで認証サービス（sampleconnect-authx）をバージョンv2.4.1からv2.3.9へロールバックします。

3. ローカルキャッシュをクリアします。

4. サービスを再起動します。

5. ノードの再起動後にヘルスチェックが通ることを確認します。

6. ヘルスチェック確認後、ALBにノードを戻します。

この作業を1ノードずつ順次実施し、30分で12ノードの切り替えを完了しました。並行して、サポート窓口から影響テナントへ「応答遅延が発生する可能性あり」の案内を送信しています。
