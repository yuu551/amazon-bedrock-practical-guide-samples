# 監査ログ ユーザーFAQ：自分の操作履歴

SampleConnect を利用するエンドユーザー向けに、自分のアカウントに関する監査ログの参照と削除請求についてまとめました。

## Q. 自分のサインイン履歴を確認したい

「マイアカウント」→「セキュリティ」→「サインイン履歴」を開いてください。直近30日分のサインイン日時、IPアドレス、デバイス、結果（成功・失敗）が表示されます。

直近30日より前の履歴を確認したい場合は、テナント管理者に依頼してください。Enterpriseプランでは管理者が最大1年分の履歴を取り出せます。

## Q. 知らないIPアドレスからのサインインがあります。どうすればいいですか

直ちに次の対応を実施してください。

1. 「マイアカウント」→「セキュリティ」→「すべてのセッションをサインアウト」を実行
2. パスワードを変更（SSO 利用の場合は IdP 側で変更）
3. MFA を有効化（未設定の場合）
4. テナント管理者に通知

SampleConnect は 24時間以内に同一アカウントから3か国以上の異なるIPでサインインを検知すると、自動でアラートを管理者に通知します。

## Q. 自分の API 操作履歴は取れますか

直近24時間分は「マイアカウント」→「API利用状況」で確認できます。それ以前の履歴はテナント管理者に依頼してください。

API操作のうち、他のユーザーのデータを参照する操作（管理者権限による代理参照）は、対象ユーザーには通知されません。テナント管理者の責任で運用されます。

## Q. アカウント削除時、私の監査ログはどうなりますか

アカウント削除（または退職に伴う管理者からの削除）後も、監査ログ上のあなたのアクションはテナントの保存期間（Enterpriseは7年）の間、保持されます。アクター情報の `ユーザーID` は維持されますが、`メールアドレス` は削除日から30日後に `[deleted-{userid}]` の形式に置換されます。

これは GDPR の「忘れられる権利」と監査要件の整合を取るための仕組みです。完全な個人特定情報の削除を要請する場合は、テナント管理者から SampleConnect サポートへ削除請求を行ってください。

## Q. 監査ログを自分で削除できますか

エンドユーザー、管理者、SampleConnect 内部の管理者を含めて、監査ログを削除する手段はありません。WORMストレージに保存されているため、規程上の保存期間が経過した時点で自動削除のみ発生します。

法執行機関の命令等で削除が必要な場合のみ、当社法務部の判断で個別対応します。
