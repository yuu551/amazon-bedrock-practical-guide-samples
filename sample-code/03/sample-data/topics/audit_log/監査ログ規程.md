# SampleConnect 監査ログ規程

本規程は、SampleConnect が記録する監査ログの範囲、保存期間、開示ルールを定めます。

## 1. 記録対象イベント

SampleConnect は次の3カテゴリのイベントを監査ログに記録します。

### 1.1 ユーザーイベント
サインイン成功・失敗、サインアウト、パスワード変更、MFA 設定変更、APIキー発行・失効。

### 1.2 管理操作イベント
ユーザー追加・削除、役割変更、プラン変更、API設定変更、SAML SSO設定変更、Webhook設定変更。

### 1.3 API操作イベント
書き込み系API呼び出し（POST/PUT/PATCH/DELETE）の全件。読み込み系（GET）はサンプリング率10%（Standardプラン）または100%（Enterpriseプラン）で記録。

## 2. 記録項目

各イベントについて、次の項目を記録します。

- イベントID（UUIDv7、タイムスタンプ含意のソート可能な形式）
- 発生時刻（UTC、ミリ秒精度）
- アクター情報（ユーザーID、メールアドレス、IPアドレス、User-Agent）
- ターゲットリソース（種別、ID、変更前後の差分）
- ソースAPI（管理コンソール、API、SCIM、Webhook）
- 結果（成功・失敗、失敗時はエラーコード）

## 3. 保存期間

| プラン | 保存期間 | 検索可能期間 |
|---|---|---|
| Free | 30日間 | 30日 |
| Standard | 1年間 | 90日 |
| Enterprise | 7年間 | 1年 |

検索可能期間を超えたログは、コンソールUIでは表示されませんが、エクスポートAPIから取得できます。Enterpriseプランでは、保存期間を最大10年まで延長可能です（要追加契約）。

## 4. 改ざん防止

監査ログは Write-Once-Read-Many（WORM）ストレージに保存され、SampleConnect 内部システムからも変更・削除はできません。各エントリには前のエントリのハッシュを含む形でチェーン化されており、欠落・改ざんが検知できる構造になっています。

SampleConnect は四半期ごとに第三者監査機関による監査ログの整合性検証を受け、報告書を Enterprise 契約者に提供します。

## 5. 開示請求

契約者は、自社テナントの監査ログをいつでもエクスポートできます。エンドユーザー個人からの開示請求（GDPR、個人情報保護法等）が SampleConnect に直接届いた場合は、当該テナントの管理者に転送し、開示の判断は管理者に委ねます。

法執行機関からの開示要求は、当社法務部での適法性確認のうえ対応します。可能な限り、当該テナントの管理者にも事前通知します。

- 2026年4月1日: チェーン化によるハッシュ検証を追加
