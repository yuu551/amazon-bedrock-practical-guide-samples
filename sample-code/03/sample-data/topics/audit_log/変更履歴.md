# 監査ログの変更履歴

SampleConnect の監査ログ機能まわりの変更履歴を時系列で記録します。

## 2026年4月1日 - チェーンハッシュによる整合性検証

各監査ログエントリに、前のエントリのSHA-256ハッシュ（`prev_hash` フィールド）を含めるよう変更しました。これにより、ログの欠落・改ざんを連鎖的に検証できるようになります。

エクスポートAPIのレスポンス、SIEM転送のいずれにも `prev_hash` が含まれます。検証用のサンプルスクリプトを `tools/audit-verify` リポジトリで公開しました。

## 2026年1月15日 - Enterpriseプラン保存期間を7年に延長

Enterpriseプランの監査ログ保存期間を 5年から 7年に延長しました。金融業界の保存要件（電子帳簿保存法・FFIEC 等）への対応を強化したものです。

既存ログも遡及して7年保存に切り替わります。料金の変更はありません。

## 2025年11月1日 - Microsoft Sentinel 連携対応

監査ログの SIEM 連携先に Microsoft Sentinel を追加しました。Common Event Format（CEF）形式での転送に対応しています。Splunk、Datadog、Sumo Logic に続く4つ目の対応SIEMです。

## 2025年8月10日 - GDPR 対応のための削除済みアカウント表記変更

アカウント削除後30日経過した監査ログのアクター情報のうち、メールアドレス欄を `[deleted-{userid}]` 形式に置換するようにしました。ユーザーIDによる追跡可能性は維持しつつ、個人特定情報の削除要請に応えられる仕組みです。

## 2025年4月1日 - 監査ログ規程の制定

監査ログの記録範囲、保存期間、改ざん防止、開示ルールを正式な規程として制定しました。これに伴い、Enterpriseプランの保存期間を 1年から 5年に延長しました（2026年1月の改訂で7年へ）。

## 2025年2月20日 - エクスポートAPI公開

監査ログを JSON Lines 形式でエクスポートできる API を公開しました。署名付きS3 URLでダウンロードする形式で、最大10GB/エクスポートまで対応します。
