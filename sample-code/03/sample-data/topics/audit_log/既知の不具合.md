# 監査ログの既知の不具合

SampleConnect の監査ログ機能に関する既知の不具合と回避策をまとめます。

## CL-AL-2026-002: SIEM転送の遅延が増加するケース

**症状**: SIEM転送の遅延が、規程上の1〜3分を超えて10分以上になる場合があります。テナント全体の監査ログ流量が毎秒1,000イベントを超えるピーク時に発生します。

**影響範囲**: 大規模利用のEnterpriseテナント。Standardプランでは発生していません。

**回避策**: 暫定的な回避策はありません。緊急のリアルタイム検知が必要な場合は、エクスポートAPIで5分間隔のポーリングを併用してください。

**修正予定**: 2026年7月のメンテナンスで転送パイプラインを増強予定。

## CL-AL-2026-001: タイムスタンプの夏時間/標準時切替時の重複

**症状**: 各国の夏時間切替時刻にイベントが集中している場合、まれに同一秒の中で順序が前後する場合があります。すべてのタイムスタンプは UTC で記録されているため、ログ自体は正しく時刻順に並びますが、同一ミリ秒のイベント間ではID（UUIDv7）の順序と時系列が完全には一致しないことがあります。

**影響範囲**: ミリ秒単位の厳密な順序が必要な分析（同時更新の競合検出等）。

**回避策**: タイムスタンプではなく `event_id`（UUIDv7）の辞書順で並び替えてください。UUIDv7 は時刻ベースなので、ミリ秒単位ではタイムスタンプと一致し、同一ミリ秒内では発生順を保証します。

**修正予定**: タイムスタンプ仕様の問題ではないため、ドキュメント整備のみで対応済み（修正はありません）。

## CL-AL-2025-011: GET イベントサンプリング率の表示揺れ

**症状**: 「セキュリティ」→「監査ログ」→「設定」画面で表示されるGETイベントのサンプリング率が、Standardプランで「10%」と表示されるべきところを「100%」と表示する場合があります。

**影響範囲**: Standardプランの管理コンソール表示のみ。実際のサンプリング率は規程通り10%です。

**回避策**: 表示の問題のみで、実際のログ取得には影響しません。

**修正予定**: 2026年5月のメンテナンスで表示修正予定。

## 修正済み

### CL-AL-2025-007: エクスポートサイズ上限超過時の不完全ファイル

**症状**: エクスポートAPI で 10GB を超えるリクエストを送ると、生成されるファイルが途中で切れる場合がありました。

**修正日**: 2025年12月12日

**修正内容**: エクスポートサイズが10GBを超えるリクエストは事前にエラー（413 Payload Too Large）を返すように変更。期間を分けて再リクエストするよう案内。

### CL-AL-2025-003: SCIM プロビジョニング時の監査ログ欠落

**症状**: SCIM 経由でユーザーが大量に追加された場合、まれに監査ログに記録されないイベントがありました。

**修正日**: 2025年9月25日

**修正内容**: SCIM処理キューに監査ログ書き込みを同期化。
