# SampleConnect APIレート制限規程

本規程は、SampleConnect API のレート制限に関する契約上のルールを定めます。本規程は2026年4月1日から適用され、改定時は別途通知します。

## 1. プラン別の初期レート上限

| プラン | 初期レート上限（毎秒） | 24時間累計上限 | 上限緩和申請 |
|---|---:|---:|---|
| Free | 10リクエスト | 50,000リクエスト | 不可 |
| Standard | 100リクエスト | 500,000リクエスト | 不可 |
| Enterprise | 1,000リクエスト | 5,000,000リクエスト | 可（要申請） |

毎秒のレートはトークンバケット方式で計測し、1秒間にバケット容量を超えるリクエストはHTTPステータス429で返却します。24時間累計は0時0分（UTC）にリセットされます。

## 2. 上限超過時の取扱い

毎秒の上限を超えた場合、429レスポンスを返却します。レスポンスヘッダの `Retry-After` に再試行までの推奨秒数（1〜60の範囲）を含めます。`X-RateLimit-Limit`、`X-RateLimit-Remaining`、`X-RateLimit-Reset` の3ヘッダで現在の状態が確認できます。

24時間累計で初期値の10倍を超過した場合、当該アカウントのAPIアクセスを6時間自動停止します。停止中のリクエストは429ではなくHTTP 503を返却します。停止解除はサポートからの連絡なしに自動で行われます。

## 3. 上限緩和申請の取扱い

Enterpriseプランの契約者は、管理コンソールから上限緩和を申請できます。申請内容は次の項目を必須とします。

- 緩和を希望する上限値（毎秒・24時間累計の両方）
- 用途と想定リクエストパターン
- 緩和開始希望日

審査は5営業日以内に完了し、承認後72時間以内に有効化されます。緩和上限は最大で初期値の10倍までとし、それ以上は個別契約とします。

## 4. SLA

SampleConnect は API リクエスト成功率99.9%を月次SLAとして保証します。429および503は本SLAの「成功」に含めません。月次成功率がSLAを下回った場合、当月利用料の最大10%を返金対象とします。

## 5. 罰則的措置

次のいずれかに該当する場合、当社は事前通知なくAPIアクセスを停止する場合があります。

- 異常なリクエストパターン（同一IPからの秒間1万件超のバースト等）が継続的に観測されたとき
- 24時間累計の停止措置（第2条）が同月内に3回以上発生したとき
- 第三者への攻撃や情報窃取と疑われるリクエストが含まれていたとき

## 6. 改定履歴

- 2025年10月1日: 制定
- 2026年4月1日: Enterpriseプラン初期上限を毎秒500から1,000に引き上げ
