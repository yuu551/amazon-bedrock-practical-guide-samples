# 課金まわりの既知の不具合

SampleConnect の課金処理に関する既知の不具合と回避策をまとめます。

## CL-BL-2026-002: 月末日跨ぎ時の日割り計算が1日ずれる

**症状**: 日本標準時（JST）23:50 以降に月末日でアップグレードを実施すると、日割り料金の計算が翌月1日付として処理される場合があります。

**影響範囲**: 月末日（28日〜31日）の23:50 JST以降にアップグレードした契約者。

**回避策**: 月末日のアップグレードは、JST 23:00 までに完了させてください。

**修正予定**: 2026年6月のメンテナンスでタイムゾーン処理を修正予定。

## CL-BL-2026-001: 解約予約後のダウングレードが意図せず実行される

**症状**: 解約予約（翌月末解約）を入れた状態で、ダウングレードを予約すると、解約予約より先にダウングレードが実行されてしまう場合があります。

**影響範囲**: 解約予約とダウングレード予約を併用するごく稀なケース。

**回避策**: 解約予約済みの契約者は、ダウングレード操作を行わないでください。プラン変更が必要な場合は、解約予約を一度取り消してからダウングレードを実施してください。

**修正予定**: 2026年5月のメンテナンスで予約処理の優先順位ロジックを修正予定。

## CL-BL-2025-010: 海外発行カードでの円建て表示誤り

**症状**: 一部の海外発行クレジットカードで、決済画面に「USD: $XXX.XX」と誤表示される場合があります。実際の請求は日本円ですが、表示上だけドル換算されています。

**影響範囲**: アメリカン・エキスプレスの一部カード。Visa、Mastercard、JCB では発生していません。

**回避策**: 表示上の誤りで、実際の請求は表示金額の日本円換算（請求書金額を当時のレートで割った数値）と一致します。決済処理自体に影響はありません。

**修正予定**: 2026年5月のメンテナンスで決済画面の通貨表示を修正予定。

## 修正済み

### CL-BL-2025-006: 請求書 PDF の改ページ崩れ

**症状**: 利用ユーザー数が50人を超えると、請求書 PDF の明細欄が改ページ位置でずれて表示されていました。

**修正日**: 2025年11月20日

**修正内容**: 請求書 PDF テンプレートの改ページ処理を修正。最大1,000人まで正しく表示されるようになりました。

### CL-BL-2025-002: クレジットカード自動更新時の決済失敗

**症状**: クレジットカード有効期限が請求日の翌月だった場合、有効期限内にも関わらず決済が失敗するケースがありました。

**修正日**: 2025年7月8日

**修正内容**: 決済プロバイダの有効期限チェックロジックを修正。
