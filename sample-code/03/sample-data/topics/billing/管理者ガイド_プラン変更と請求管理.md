# 課金管理者ガイド：プラン変更と請求管理

SampleConnect 管理者向けに、プラン変更、支払い方法変更、請求書管理の操作手順をまとめます。

## プラン変更操作

「請求情報」→「プラン変更」を開きます。現在のプランと、変更可能なプランが一覧表示されます。

### アップグレードの手順

1. 移行先のプラン（例: Standard → Enterprise）を選択。
2. 「料金プレビュー」セクションで、当月の日割り料金と翌月以降の通常月額が表示されます。日割り対象期間と計算式（`月額 × 残日数 ÷ 当月日数`）も明示されます。
3. 「変更を確認」を押すと、最終確認モーダルが開きます。
4. 「変更を実行」を押すと、即座にプラン機能が切り替わります。日割り料金は翌月請求に加算されます。

### ダウングレードの手順

1. 移行先のプラン（例: Enterprise → Standard）を選択。
2. プレビューで「翌月1日から適用」と表示されます。日割り返金がない旨も明記されます。
3. ダウングレード時に失われる機能が一覧表示されます。SAML SSO、監査ログ7年保存、データレジデンシー選択など、Enterprise 限定機能を利用中の場合は警告が出ます。
4. 「変更を確認」「変更を実行」で確定。

ダウングレード予約は翌月1日まで取り消し可能です。

## 支払い方法

SampleConnect は次の3種類の支払い方法に対応しています。

| 支払い方法 | 対応プラン | 反映までの所要時間 |
|---|---|---|
| クレジットカード | 全プラン | 即時 |
| 銀行振込（請求書払い） | Standard 以上 | 振込確認まで最大3営業日 |
| 口座振替 | Enterprise（要事前登録） | 月次自動引落し |

### クレジットカード変更

「請求情報」→「支払い方法」→「カード情報を更新」から、新しいカード情報を入力します。次回請求から新しいカードに切り替わります。

### 請求書払い設定

請求書払いを希望する場合、「請求情報」→「支払い方法」→「請求書払いに変更」を選択します。事業者情報、請求書送付先メールアドレス、振込元口座を入力します。

申込から審査完了まで5営業日かかります。承認後、毎月20日に請求書 PDF が自動でメール送付され、月末までに振込いただく運用になります。

## 請求書のダウンロード

「請求情報」→「請求履歴」から、過去24か月分の請求書を PDF でダウンロードできます。請求書には次の項目が含まれます。

- 請求番号（`INV-YYYYMM-XXXX`）
- 発行日
- 支払期日
- プラン名と利用期間
- 利用料金（税抜・消費税・税込）
- 振込先銀行口座（請求書払いのみ）

## 領収書の再発行

支払い完了後、領収書 PDF が自動生成されます。「請求履歴」→「領収書」からダウンロードしてください。

24か月より古い領収書は、営業窓口（`billing@sampleconnect.example`）へメールでお問い合わせください。3営業日以内に再発行します。

## 解約申請

「請求情報」→「解約申請」から実施します。解約理由（任意）と確認事項のチェックを経て確定します。

解約後30日以内であれば、「復帰申請」から復活できます。30日を超えるとデータは完全削除され、復旧できません。
