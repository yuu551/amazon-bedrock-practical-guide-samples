# 課金規程の変更履歴

SampleConnect の課金関連規程・運用の変更履歴を時系列で記録します。

## 2026年4月1日 - ダウングレード時の日割り返金を廃止

これまで月の途中でダウングレードを実施した場合、当月分の差額を翌月から日割り返金していましたが、計算複雑化と返金処理コストを理由に廃止しました。

ダウングレード後の新プラン適用は翌月1日からとし、当月分は元のプラン料金で請求します。返金処理がなくなる代わりに、ダウングレード予約は翌月1日まで取り消し可能としました。

## 2026年1月1日 - Enterprise プラン月額改定

Enterprise プランの月額を 150,000円から 200,000円に改定しました。専任 CSM・SCIM対応・監査ログ保存期間延長などの機能拡張に伴うものです。

新規契約は即日適用、既存契約は2026年7月1日から新料金が適用されます。経過措置として、6か月前までに事前通知済みです。

## 2025年12月15日 - インボイス番号の請求書記載

請求書および領収書に、適格請求書発行事業者番号（`T1234567890123`）を記載するようにしました。インボイス制度対応により、仕入税額控除の対象となります。

## 2025年9月1日 - 請求書払いのリードタイム短縮

請求書払い申込から承認までの所要日数を 10営業日から 5営業日に短縮しました。審査プロセスの自動化によるものです。

## 2025年4月1日 - 課金規程の制定

それまでサポート問い合わせ窓口で個別に運用していた課金関連ルールを、正式な規程として制定しました。プラン変更時の日割り、解約規程、消費税、領収書発行を明文化しました。
