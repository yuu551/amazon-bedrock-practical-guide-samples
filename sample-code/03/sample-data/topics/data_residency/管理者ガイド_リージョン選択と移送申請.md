# データ所在地 管理者ガイド：リージョン選択と移送申請

SampleConnect 管理者向けに、リージョン選択、リージョン変更申請、移送中の運用上の注意点をまとめます。

## 初回リージョン選択

新規契約時、サインアップウィザード画面で次の選択肢からリージョンを指定します。

- **東京リージョン**: 日本国内のみで処理。個人情報保護法対応に最適。
- **米国西部リージョン**: 北米利用者中心の場合、レイテンシ最小。HIPAA 対応可（Enterpriseのみ、BAA締結要）。
- **欧州中央リージョン**: GDPR 厳格対応が必要な場合。DPA、SCC は契約書で締結済み。

選択判断の参考として、想定ユーザーの所在地、データに含まれる個人情報の管轄国、適用される業界規制を考慮してください。

## リージョン変更申請（Enterprise のみ）

「セキュリティ」→「データ所在地」→「リージョン変更を申請」から実施します。

### 申請手順

1. 移送先リージョンを選択。
2. 変更理由を選択（拠点移転／法令対応／パフォーマンス改善／その他）。
3. 希望開始日を入力（営業日10日後以降）。
4. 移送中のサービス停止可能ウィンドウ（最大4時間）を選択。
5. 申請を送信。

### 申請から完了までの流れ

| ステップ | 期間 | 内容 |
|---|---|---|
| 1. 申請受付 | 即日 | 申請内容の自動検証 |
| 2. 法務確認 | 3営業日 | 移送先リージョンの法令適合性確認 |
| 3. データ整合性チェック | 2営業日 | 移送対象データのバックアップ整合性検証 |
| 4. 顧客との実施日調整 | 1〜3営業日 | 移送実施日時の最終調整 |
| 5. 移送実施 | 最大4時間 | サービス停止のうえ、データ移送 |
| 6. 検証と切替 | 1〜2営業日 | 新リージョンでの稼働確認後、旧リージョンの削除 |

## 移送中の運用

移送実施日のサービス停止時間中、すべての API 呼び出しと管理コンソールアクセスは HTTP 503 を返します。エンドユーザーへの事前周知が必要です。

移送完了後、API エンドポイントの URL は同じですが、内部的に新リージョンへルーティングされます。アプリケーション側の変更は不要です。

## DPA・SCC・BAA の取得

各種データ保護関連書類は、「セキュリティ」→「コンプライアンス」から PDF をダウンロードできます。

| 書類 | 対象 | 用途 |
|---|---|---|
| DPA（データ処理契約書） | 全リージョン | GDPR、個人情報保護法対応 |
| SCC（標準契約条項） | 欧州中央 + EU域外移送時 | EU域外への第三国移送 |
| BAA（HIPAA Business Associate Agreement） | 米国西部 Enterprise | 米国医療データ保護 |

書類は SampleConnect の代表者署名済み PDF を提供します。契約者側で別途、自社印鑑による署名と SampleConnect 法務部への返送が必要です。

## サブプロセッサ一覧

データ処理に関わる委託先（サブプロセッサ）一覧は、「セキュリティ」→「コンプライアンス」→「サブプロセッサ」から確認できます。新規追加・変更時は、効力発生30日前までに管理者宛にメール通知します。

## 監査レポート

第三者機関による SOC 2 Type II、ISO 27001、ISO 27017 の監査レポートを年次で公開しています。最新版は「セキュリティ」→「コンプライアンス」→「監査レポート」からダウンロードできます。
