# SampleConnect データ所在地規程

本規程は、SampleConnect が顧客データを保存するリージョン、リージョン間の移送、各国法令への対応に関する契約上のルールを定めます。

## 1. 提供リージョン

SampleConnect は次の3リージョンでサービスを提供しています。

| リージョン | コード | 主データセンター所在地 | バックアップ所在地 |
|---|---|---|---|
| 東京 | `ap-northeast-1` | 日本（東京） | 日本（大阪） |
| 米国西部 | `us-west-2` | アメリカ合衆国（オレゴン州） | アメリカ合衆国（ネバダ州） |
| 欧州中央 | `eu-central-1` | ドイツ（フランクフルト） | ドイツ（ベルリン） |

各リージョンのバックアップは、同一国内の地理的に離れた場所に保管されます。リージョンを跨いだバックアップは行いません。

## 2. データの種類とリージョン

SampleConnect が扱うデータは次の3種類に分類されます。

### 2.1 顧客コンテンツ
契約者がSampleConnectに保存・送信するデータ（ユーザー情報、アップロードファイル、API送受信データ等）。契約時に選択したリージョンにのみ保存され、他リージョンには複製しません。

### 2.2 メタデータ
顧客コンテンツの管理に必要な情報（ユーザーID、テナントID、リソースID、タイムスタンプ等）。顧客コンテンツと同じリージョンに保存します。

### 2.3 運用データ
監査ログ、システムメトリクス、課金情報等。顧客コンテンツと同じリージョンに保存しますが、課金情報のうち請求書発行に必要な範囲は、本社所在地（日本）の経理システムにも保管されます。

## 3. リージョン選択と変更

### 3.1 初回選択
契約時に管理者がリージョンを選択します。プランごとに選択可能なリージョンは次のとおりです。

| プラン | 選択可能リージョン |
|---|---|
| Free | 東京のみ |
| Standard | 東京、米国西部 |
| Enterprise | 東京、米国西部、欧州中央 |

### 3.2 リージョン変更
契約後のリージョン変更は、Enterprise プラン契約者のみ申請可能です。変更には次の制約があります。

- 申請から完了まで最大10営業日
- 移送中はサービスが最大4時間停止
- 同一年度内の変更は最大1回

リージョン変更時、データはすべて新リージョンへ移送され、旧リージョンからは7日以内に完全削除されます。

## 4. リージョン間の移送

通常運用において、顧客コンテンツがリージョン間を移送されることはありません。例外として次の3ケースのみ移送が発生します。

1. 第3条のリージョン変更申請
2. 災害復旧時の代替リージョン稼働（後述）
3. 法執行機関の命令に基づく開示

## 5. 災害復旧

リージョン全体が利用不能（複数アベイラビリティゾーン同時障害）になった場合、SampleConnect は最大72時間以内に同地理圏の代替リージョンへの一時的な切替を行う場合があります。

各リージョンの代替先は次のとおりです。

- 東京 → 大阪リージョン（日本国内、地域内代替）
- 米国西部 → 米国東部リージョン（米国内、地域内代替）
- 欧州中央 → 欧州西部リージョン（EU内、GDPR域内代替）

地理圏を跨いだ代替リージョン稼働は行いません。

## 6. 各国法令への対応

| 法令 | 対応リージョン | 対応内容 |
|---|---|---|
| 個人情報保護法（日本） | 東京 | 完全対応 |
| GDPR（EU） | 欧州中央 | DPA締結、SCC対応 |
| CCPA（カリフォルニア） | 米国西部 | プライバシー権利の運用 |
| HIPAA（米国医療） | 米国西部のEnterpriseのみ | BAA締結要 |
