# データ所在地の変更履歴

SampleConnect のデータ所在地まわりの変更履歴を時系列で記録します。

## 2026年4月1日 - 災害復旧時の代替リージョン規定を追加

リージョン全体が利用不能になった場合の代替リージョン稼働ルールを規程に明記しました。地理圏を跨いだ代替（例: 東京リージョン障害時に米国へ移送）は行わず、同地理圏内（東京 → 大阪）に限定します。

これは GDPR の域外移転制限、個人情報保護法の越境制限に配慮したものです。

## 2025年11月15日 - 欧州中央リージョン追加

ドイツ（フランクフルト）に欧州中央リージョン（`eu-central-1`）を追加しました。GDPR 域内でのデータ処理を必要とする欧州顧客向けです。

東京リージョンまたは米国西部リージョンの既存契約者は、Enterpriseプランへのアップグレードと「リージョン変更申請」を組み合わせて欧州中央へ移送できます。移送に伴うダウンタイムは最大4時間です。

## 2025年9月20日 - HIPAA 対応開始

米国西部リージョンの Enterprise プランに限り、HIPAA 対応を開始しました。BAA（Business Associate Agreement）の締結が必要です。医療系データの取り扱いに対応します。

## 2025年6月1日 - データ所在地規程の制定

それまで個別契約条項の中に分散していたデータ所在地ルールを、独立した規程として制定しました。リージョン選択、リージョン変更、災害復旧、各国法令対応を明文化しました。

制定時のリージョンは東京と米国西部の2つでした。

## 2025年3月10日 - 米国西部リージョン公開

米国西部リージョン（`us-west-2`、オレゴン州）でのサービス提供を開始しました。それまで東京リージョンのみだった SampleConnect を、北米顧客向けに拡張したものです。
