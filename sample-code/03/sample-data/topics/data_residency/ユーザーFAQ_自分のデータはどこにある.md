# データ所在地 ユーザーFAQ：自分のデータはどこにある

SampleConnect のエンドユーザーから受ける、データ所在地まわりのよくある質問をまとめました。

## Q. 自分のデータはどのリージョンに保存されていますか

「マイアカウント」→「データ情報」を開くと、所属テナントが選択しているリージョンと、データセンター所在地が表示されます。例えば次のように表示されます。

```
リージョン: 東京（ap-northeast-1）
プライマリデータセンター: 日本（東京都）
バックアップデータセンター: 日本（大阪府）
```

リージョンを跨いだデータ複製は行わないため、表示されているデータセンター以外にあなたのデータは存在しません。

## Q. テナント管理者がリージョンを変更したらどうなりますか

リージョン変更時、すべてのデータが新リージョンに移送されます。移送中（最大4時間）はサービスが停止しますが、移送完了後は同じ URL で利用可能です。

テナント管理者から事前に変更計画の通知があります。SampleConnect 自体からエンドユーザーに直接通知することはありません。

## Q. SampleConnect の社員は私のデータにアクセスできますか

通常運用において、SampleConnect 社員が顧客コンテンツに直接アクセスすることはありません。アクセスが発生するのは次の3ケースのみで、いずれも監査ログに記録されます。

1. **顧客からのサポート要請**: 管理者が「サポートアクセス」を明示的に許可した場合のみ。最大72時間で自動失効。
2. **緊急インシデント対応**: サービス停止等の緊急時。事後30日以内にテナント管理者へ通知。
3. **法執行機関の命令**: 日本国法および当該リージョン法に基づく命令時。可能な限り、当該テナントの管理者にも事前通知。

## Q. データを完全削除してほしい場合はどうすればいいですか

GDPR の「忘れられる権利」や、日本の個人情報保護法に基づく削除請求がある場合、テナント管理者経由で SampleConnect サポートへ依頼してください。

エンドユーザー個人から SampleConnect へ直接削除請求が届いた場合、テナント管理者へ転送します。SampleConnect は契約者（テナント）のデータプロセッサーであり、データコントローラーは契約者です。

## Q. 海外出張先からアクセスしても、データは移動しませんか

アクセス元の国に関わらず、データはテナントが選択したリージョンにのみ保存されます。海外からの API 呼び出しがあっても、データは元のリージョンを離れません。

ただし、API 呼び出しのレスポンスは一時的にあなたのデバイスに保存される（ブラウザのキャッシュ等）ため、ブラウザの設定でローカルキャッシュをクリアしないと、デバイス上にコピーが残ります。

## Q. SampleConnect が利用するクラウドプロバイダはどこですか

リージョンごとに次のクラウドプロバイダを利用しています。

- 東京・大阪: Amazon Web Services（AWS）東京・大阪リージョン
- 米国西部・東部: AWS US-West-2 / US-East-1 リージョン
- 欧州中央・西部: AWS Frankfurt / Ireland リージョン

サブプロセッサーの一覧および契約状況は、テナント管理者が「コンプライアンス」画面から確認できます。
