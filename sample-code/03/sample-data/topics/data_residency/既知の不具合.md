# データ所在地の既知の不具合

SampleConnect のデータ所在地機能に関する既知の不具合と回避策をまとめます。

## CL-DR-2026-001: リージョン変更後のメトリクス可視化遅延

**症状**: リージョン変更を実施したテナントで、移送完了後 24時間以内は管理コンソールの「使用状況」グラフが部分的に欠落する場合があります。

**影響範囲**: リージョン変更を実施したテナント。新リージョンに移送した直後の表示のみ。

**回避策**: 24時間経過後に再度確認してください。実データは正常に保存されており、表示の問題のみです。

**修正予定**: 2026年6月のメンテナンスでメトリクス集計パイプラインの修正予定。

## CL-DR-2025-014: バックアップ整合性レポートの欧州中央リージョン未対応

**症状**: 欧州中央リージョンを利用するテナントで、四半期末の「バックアップ整合性レポート」がメール送付されない場合があります。

**影響範囲**: 欧州中央リージョンを利用する Enterprise テナント。

**回避策**: 「セキュリティ」→「コンプライアンス」→「監査レポート」から手動でダウンロードしてください。データ自体は正常に検証されています。

**修正予定**: 2026年5月のメンテナンスで自動メール送付機能を欧州中央にも展開予定。

## CL-DR-2025-013: HIPAA BAA 締結フローの一部画面表示問題

**症状**: 米国西部 Enterprise プランの HIPAA BAA 締結申請画面で、署名欄の表示が崩れる場合があります（Safari 17.x 環境）。

**影響範囲**: Safari 17.x で BAA 締結を実施するケース。

**回避策**: Chrome、Firefox、Edge を使用してください。または Safari 18 以降にアップデートしてください。

**修正予定**: 2026年5月のメンテナンスで Safari 17 互換性を修正予定。

## 修正済み

### CL-DR-2025-009: リージョン間データ漏洩リスク（事前防止）

**症状**: 内部監査で、災害復旧テスト時に異リージョンへデータが一時的にコピーされる経路が発見されました。本番環境で発動した事実はなく、テスト環境でのみ確認された問題です。

**修正日**: 2025年12月20日

**修正内容**: 災害復旧経路を地理圏内に限定する制御を本番・テスト環境ともに追加。テスト環境でも越境コピーは発生しない構成に変更。

### CL-DR-2025-005: DPA PDF の電子署名検証エラー

**症状**: DPA PDF の電子署名が、一部の PDF リーダーで「検証失敗」と表示される問題がありました。署名自体は有効でしたが、PDF リーダー側の互換性問題です。

**修正日**: 2025年9月15日

**修正内容**: 電子署名の証明書チェーンを一般的な PDF リーダーで検証可能な形式に変更。
