# SAML SSO の既知の不具合

SampleConnect の SAML SSO 機能に関する既知の不具合と回避策をまとめます。

## CL-SSO-2026-003: 属性 `groups` の値に半角スペースが含まれるとマッピングが失敗

**症状**: IdP から渡される `groups` クレームの値に半角スペースが含まれている場合、SampleConnect の役割マッピング処理がエラーになり、ユーザーは `Member` ロールで作成されます。

**影響範囲**: SAML SSO 利用テナント全般。特に Microsoft Entra ID で「Display Name」をグループID代わりに使っているケース。

**回避策**: IdP 側でグループ名を半角スペースなしの ASCII 文字列に変更する、またはグループID（GUID）をクレームに含めるよう設定変更してください。

**修正予定**: 2026年6月のメンテナンスで対応予定。

## CL-SSO-2026-001: NotOnOrAfter のタイムゾーン解釈ずれ

**症状**: SAML Response の `NotOnOrAfter` 属性が UTC 表記でない場合、まれに認証が拒否されることがあります。

**影響範囲**: 一部の自社製IdP（オンプレミス AD FS の特定バージョン等）。Okta、Entra ID、Google Workspace では発生していません。

**回避策**: IdP 側で `NotOnOrAfter` を UTC（末尾`Z`）で出力するよう設定してください。AD FS 2019 以降は標準で UTC 出力ですが、AD FS 2016 以前は要設定確認です。

**修正予定**: 2026年7月のメンテナンスで対応予定。

## CL-SSO-2025-009: SCIM プロビジョニング有効化時、既存JITユーザーの重複作成

**症状**: JIT プロビジョニングで作成済みのユーザーが存在するテナントで SCIM 2.0 を新規有効化すると、SCIM 側から同一メールアドレスのユーザーが重複作成される場合があります。

**影響範囲**: JIT 有効期間中にユーザーが作成され、その後 SCIM に移行したテナント。

**回避策**: SCIM 有効化前に、IdP 側で SCIM プロビジョニング対象ユーザーを「初期同期」してください。SampleConnect 側は同一メールアドレスをマージ処理し、重複が解消されます。

**修正予定**: 2026年5月のメンテナンスで自動マージ機能を追加予定。

## 修正済み

### CL-SSO-2025-006: IdP-Initiated でのRelayState欠落

**症状**: IdP-Initiated サインイン時、RelayState が IdP 側で設定されていないと、SampleConnect のダッシュボードではなくエラー画面に遷移していました。

**修正日**: 2025年11月3日

**修正内容**: RelayState が空または未指定の場合、デフォルトでダッシュボードに遷移するよう実装変更。

### CL-SSO-2025-002: 署名検証に5秒以上かかる場合のタイムアウト

**症状**: 大規模IdPのメタデータ（証明書チェーンが深い場合等）で署名検証に5秒以上かかると、サインインがタイムアウトしていました。

**修正日**: 2025年8月18日

**修正内容**: 署名検証タイムアウトを5秒から30秒に延長。
