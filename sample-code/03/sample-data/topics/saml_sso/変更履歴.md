# SAML SSO 変更履歴

SampleConnect の SAML SSO 機能まわりの変更履歴を時系列で記録します。

## 2026年4月1日 - SCIM 2.0 プロビジョニング対応

これまで JIT プロビジョニングのみだった機能に、SCIM 2.0 プロビジョニングを追加しました。SCIM を有効化すると、IdP 側でユーザーを削除した際に SampleConnect 側も自動で無効化されます。

JIT との併用は仕様上サポートしないため、SCIM を有効化すると JIT は自動的に無効化されます。SCIM 有効化前に JIT で作成されたユーザーは、SCIM 有効化後に IdP 側で再度プロビジョニング操作（同期）が必要です。

## 2025年12月1日 - RSA-SHA1 非推奨化

SAML 署名アルゴリズム RSA-SHA1 を非推奨としました。2026年6月30日までは警告ログを出しつつ受け付けますが、2026年7月1日以降は RSA-SHA1 で署名された SAML Response は拒否されます。

該当する IdP の管理者は、2026年6月30日までに RSA-SHA256 への移行を完了してください。

## 2025年9月15日 - SAML SSO の正式提供開始

ベータ提供だった SAML 2.0 ベースの Single Sign-On を正式機能として提供開始しました。Okta、Microsoft Entra ID、Google Workspace、OneLogin の4つのIdPで動作確認済みです。

Enterpriseプラン契約者は、追加料金なしで利用できます。

## 2025年7月20日 - Single Logout（SLO）対応

SAML Single Logout プロファイルに対応しました。SampleConnect からログアウトすると、IdP 側のセッションも同時に終了します（SP-Initiated SLO のみ、HTTP-Redirect バインディング）。

IdP-Initiated SLO は技術的制約により未対応です。

## 2025年5月10日 - SAML SSO のベータ提供開始

Enterpriseプランの一部契約者向けに SAML 2.0 SSO のベータ提供を開始しました。
