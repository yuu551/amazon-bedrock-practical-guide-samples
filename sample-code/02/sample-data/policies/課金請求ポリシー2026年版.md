# SampleConnect Platform 課金請求ポリシー

本ポリシーは、SampleConnect Platformの月額課金、プラン変更時の請求調整、請求書払い、サービスクレジットの請求への反映方法を定めます。前版は本版の適用開始をもって失効します。

## 適用範囲

本ポリシーは、Standardプランおよびそれ以上のサブスクリプション契約に適用されます。Freeプランは無償のため請求書発行はありません。Enterpriseプラン専用条項は別途記載します。

## 月額課金と支払サイト

請求は月単位（締め日：毎月末日）で確定し、翌月初旬に請求書が発行されます。請求書払いの支払期日は、月末締め翌月末日（土日祝の場合は翌営業日）です。クレジットカード払いの場合は、請求確定日に自動決済されます。請求通貨は日本円のみで、国外送金には対応しません。

## プラン変更時の請求調整

| 変更パターン | 反映タイミング | 請求調整 |
|---|---|---|
| Free→Standard | 即時（15分以内） | 当月分は日割り計算 |
| Standard内のシート数変更 | 即時（15分以内） | 当月分は日割り計算 |
| Standard→Enterprise | 営業窓口経由で約2週間 | 切り替え月から新プラン金額。前プラン分は日割り |
| Enterprise→Standard | 営業窓口経由で約2週間 | 翌月から新プラン金額。当月は前プラン金額のまま |

## サービスクレジットの反映

現行版SLAポリシーに基づき付与されたサービスクレジットは、付与判定の翌月以降の請求書から差し引きます。複数月にまたがる場合は、最終的な未消化分は契約終了時に失効します。現金返金や他社製品との交換には応じません。

## 支払い遅延時の扱い

支払期日を超過した請求が発生した場合、最長14日間の猶予期間を経て、テナント単位での書き込み機能の停止に進みます。書き込み停止後30日経過しても支払いがない場合は、テナント全体の利用停止となり、データの復旧は支払い完了後30日以内に申請が必要です。
