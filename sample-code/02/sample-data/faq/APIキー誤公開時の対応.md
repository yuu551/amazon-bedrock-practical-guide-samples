# APIキー誤公開時の対応

質問: APIキーを誤って公開した場合、どう対応しますか。

回答: 公開を検知したら、まずSampleConnect管理コンソールの「API設定」→「APIキー」から該当キーを即時失効してください。失効はリアルタイムで反映され、以降の認証は失敗します。続いて、新しいAPIキーを発行し、利用中のシステムへ差し替えます。GitHubなど公開リポジトリへ漏えいした場合は、コミット履歴の書き換えではなくキー失効・再発行を優先してください。失効後は、監査ログ（`api.key.used`イベント）から漏えい期間中の不正利用有無を確認し、必要に応じてサポート窓口へインシデントとして連絡します。

補足: GitHubのシークレットスキャン連携やローテーション運用の詳細は「API認証・監査ログ管理ガイド」を参照してください。サポート担当者向けの調査手順は「APIキー漏えいインシデント対応手順」を参照してください。
