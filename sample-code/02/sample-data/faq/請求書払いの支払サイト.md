# 請求書払いの支払サイト

質問: 請求書払いの支払サイトはいつですか。

回答: 請求書払い（後払い）は、StandardプランとEnterpriseプランで利用できます。締め日は毎月末日、支払期日は翌月末日（土日祝日の場合は翌営業日）の月末締め翌月末払いです。通貨は日本円のみで、海外送金には対応しません。Freeプランは無償のため請求書発行はありません。Standardプランは標準でクレジットカード払い、Enterpriseプランは申込時に請求書払いを選択できます。

補足: 支払い遅延時の扱いと利用停止条件は「課金請求ポリシー2026年版」、プラン変更時の請求調整は「プラン変更の反映タイミング」を参照してください。
