# 緊急メンテナンスの通知方法

質問: 緊急メンテナンスはどのように通知されますか。

回答: 重大なセキュリティ脆弱性の修正や、サービス停止を回避するための緊急メンテナンスは、最短で実施30分前に告知します。経路は、SampleConnect管理コンソールのバナー通知、管理者宛てメール、Enterpriseプラン向けSlack/Teams連携通知の3つです。事象の重大度によっては、ステータスページの「発生中」セクションに事前掲出します。実施完了後はポストモーテムを作成し、Enterpriseプランの顧客には24時間以内に共有します。

補足: 計画メンテナンスとの違いや、対象範囲の判断基準は「メンテナンス運用ポリシー」、サービスクレジットへの影響は「SLAポリシー2026年版」を参照してください。
