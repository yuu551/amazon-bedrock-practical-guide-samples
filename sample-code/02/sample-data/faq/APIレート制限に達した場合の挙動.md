# APIレート制限に達した場合の挙動

質問: APIレート制限に達した場合、どのような応答になりますか。

回答: レート制限に達したリクエストは、HTTPステータス`429 Too Many Requests`を返します。レスポンスヘッダーには、再試行までの推奨待機秒数を示す`Retry-After`、現在のウィンドウでの残り回数を示す`X-RateLimit-Remaining`、ウィンドウのリセット時刻を示す`X-RateLimit-Reset`が含まれます。直近24時間のレート超過が累計1万回を超えた場合は、テナント単位で1時間の一時停止が自動適用されます。停止が発生すると、管理者宛てに警告メールが送信されます。

補足: 上限値はプランごとに異なります。Enterpriseプランの上限は「EnterpriseプランのAPIレート上限」を、上限緩和の申請手順は「APIレート上限緩和申請手順」を参照してください。
