# 計画メンテナンスの通知方法

質問: 計画メンテナンスはどのように通知されますか。

回答: 計画メンテナンスは、実施開始の72時間以上前に4つの経路で告知します。1つ目は管理者宛てメール、2つ目はSampleConnect管理コンソール上部のバナー通知、3つ目は公開ステータスページ（status.sampleconnect.example.com）、4つ目はEnterpriseプラン向けのSlack/Teams連携通知です。全プランの管理者は1つ目と2つ目を受け取り、3つ目はテナント未契約の利用者でも閲覧できます。実施1時間前にも、同じ経路でリマインドが配信されます。

補足: 計画メンテナンスの対象範囲とサービス影響は事前通知の本文に記載します。緊急メンテナンスの扱いは「緊急メンテナンスの通知方法」を参照してください。
