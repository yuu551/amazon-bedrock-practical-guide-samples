# IPアドレス制限の設定範囲

質問: IPアドレス制限はどの単位で設定できますか。

回答: IPアドレス制限は、テナント単位とユーザーグループ単位の2レイヤで設定できます。それぞれCIDR形式（IPv4およびIPv6）で記述し、テナント単位では最大200件、ユーザーグループ単位では最大50件まで登録できます。両方を設定した場合は、テナント単位の許可リストで一次ふるい分けされたうえで、ユーザーグループ単位の許可リストが評価されます。設定は、SampleConnect管理コンソールの「セキュリティ」→「ネットワーク制御」→「IP許可リスト」から行えます。

補足: IP許可リストの運用ガイドラインは「ネットワークセキュリティ運用手順」、Enterpriseプラン専用の地域制限・ASN制限の詳細は「Enterpriseプラン機能ガイド」を参照してください。
