# 監査ログの保持期間

質問: 監査ログはプランごとに何日保存されますか。

回答: SampleConnect Platformの監査ログ保持期間は、プランによって異なります。Freeプランは7日間、Standardプランは90日間、Enterpriseプランは730日間（24ヶ月）です。保持期間を超えたログは、自動的に削除されます。保持期間内のログは、SampleConnect管理コンソールの「セキュリティ」→「監査ログ」から閲覧でき、長期保管が必要な場合は監査ログのエクスポート機能でCSVまたはJSON Lines形式に書き出せます。

補足: 保持期間の正式な根拠は「監査ログ保存ポリシー」、エクスポートやSIEM連携の方法は「監査ログのエクスポート方法」を参照してください。
