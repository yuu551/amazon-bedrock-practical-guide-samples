# EnterpriseプランのAPIレート上限

質問: EnterpriseプランのAPIレート制限はいくつですか。

回答: Enterpriseプランの標準レート上限は、テナントごとに1,000リクエスト/秒です。Standardプランは100リクエスト/秒、Freeプランは10リクエスト/秒となります。バースト許容は、いずれのプランも標準値の1.5倍までです。利用状況は、SampleConnect管理コンソールの「使用状況」→「APIメトリクス」から、テナント全体・APIキー単位・エンドポイント単位で確認できます。Enterpriseプランで継続的に上限へ達している場合は、サポート窓口から上限緩和を申請できます。

補足: 申請には、直近30日のレート使用状況グラフと、緩和を要する業務理由を添えてください。詳細手順は「APIレート上限緩和申請手順」を参照してください。
