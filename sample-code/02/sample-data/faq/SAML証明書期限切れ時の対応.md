# SAML証明書期限切れ時の対応

質問: SAML証明書の期限切れ通知が来たらどう対応しますか。

回答: SampleConnect Platformは、IdP証明書の有効期限の30日前と7日前に管理者宛てメールでリマインドを送ります。通知を受け取ったら、まずIdP側で新しい署名証明書を発行し、IdP側のメタデータXMLを最新化してください。続いてSampleConnect管理コンソールの「SSO設定」→「IdPメタデータ」から、最新のメタデータXMLを再アップロードします。アップロード後は、必ずテスト接続を行い、SAMLログの`SignatureValidationFailed`が発生していないことを確認します。証明書を切り替える時間帯は、業務時間外を推奨します。

補足: 切り替え手順の詳細は「SAML認証設定ガイド」、切り替えに失敗した場合のロールバック手順は「SAMLトラブルシューティング手順」を参照してください。
