# SLA違反時のサービスクレジット

質問: SLA違反時のサービスクレジットはどう決まりますか。

回答: 月間稼働率が、Enterpriseプランの保証値（99.95%）を下回った場合、以下のとおりサービスクレジットを月額利用料に対して付与します。99.0%以上99.95%未満は10%、95.0%以上99.0%未満は25%、95.0%未満は50%です。Standardプランは保証値99.9%を基準に、同様の段階で算定します。サービスクレジットは現金返金ではなく、翌月以降の請求書から差し引く形で適用されます。

補足: 稼働率の計算方法、対象外となる事象、申請に必要な情報は「SLAポリシー2026年版」、申請期限と窓口は「サービスクレジットの申請期限」を参照してください。
