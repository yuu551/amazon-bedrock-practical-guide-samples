# Managed KBの回答とイベントの例

SampleConnectの架空の資料を使った実行例です。JSONLには、検索結果、回答、イベントの到着時刻を保存しています。

| ファイル | 検索と回答の方式 |
|---|---|
| [agentic-managed](2026-10-07-agentic-managed.jsonl) | Agentic Retrievalが検索と回答生成を行う |
| [agentic-model](2026-10-07-agentic-model.jsonl) | Agentic Retrievalで検索し、Claude Sonnet 4.6が回答する |
| [retrieve-model](2026-10-07-retrieve-model.jsonl) | Retrieveで検索し、Claude Sonnet 4.6が回答する |

各方式を1回ずつ実行した記録です。性能の優劣を示す比較ではありません。バケット名などの識別子は例示用の値に置き換えています。
