# SampleConnect Platform SLA案内ポリシー（試案）

> **適用開始日**: 2026-04-01
> **改訂日**: 2026-04-01
> **適用範囲**: Standard以上のサブスクリプション契約

SampleConnect Platformの月間稼働率保証値は以下とします。

| プラン | 月間稼働率の保証値 |
|---|---|
| Standard | 99.0% |
| Enterprise | 99.5% |

サービスクレジットは月額利用料に対して以下の割合で付与します。

| 稼働率 | クレジット率 |
|---|---|
| 99.0%以上保証値未満 | 5% |
| 95.0%以上99.0%未満 | 12% |
| 95.0%未満 | 25% |

申請窓口はSampleConnectサポート窓口で、申請期限は障害発生月の翌々月末日までとします。

サービスクレジットは現金返金で支払います。
