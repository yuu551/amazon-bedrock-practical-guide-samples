# Enterpriseプラン機能ガイド

## 概要

SampleConnect PlatformのEnterpriseプランは、大規模組織向けに設計された最上位プランです。セキュリティ、コンプライアンス、運用管理の各領域で、StandardプランやFreeプランにはない高度な機能を提供します。本ガイドでは、Enterpriseプランで利用できる主要機能とその仕様を説明します。

## 監査ログ

Enterpriseプランでは、監査ログの保持期間は2年間です。Standardプランの90日、Freeプランの30日と比較して、長期間にわたる操作履歴の追跡が可能です。監査ログには、ユーザーの認証イベント、権限変更、データの作成・更新・削除、管理画面での設定変更など、すべての操作が記録されます。

監査ログはSampleConnect管理画面の「セキュリティ」→「監査ログ」から確認できます。日時、ユーザー、操作種別、対象リソースによるフィルタリングに対応しており、CSV形式でのダウンロードも可能です。

また、Enterpriseプランでは外部サービスへのエクスポートに対応しています。Amazon CloudWatch Logsへのリアルタイムエクスポートを設定することで、既存の監視基盤と統合した分析が行えます。さらに、2026年4月のアップデートでAmazon S3バケットへの長期保管エクスポートにも対応しました。これにより、2年の保持期間を超えた監査ログの保管も実現できます。詳細な設定手順は「API認証・監査ログ管理ガイド」を参照してください。

## SLA（サービスレベル保証）

Enterpriseプランでは、月間稼働率99.95%のSLAを保証しています。SLAの算出対象は、SampleConnect PlatformのAPIエンドポイントおよび管理画面です。計画メンテナンス（事前に72時間以上前に通知）の時間帯は算出対象から除外されます。

SLA違反が発生した場合、稼働率に応じたサービスクレジットが適用されます。

- 稼働率99.0%以上99.95%未満: 月額利用料の10%をクレジット
- 稼働率95.0%以上99.0%未満: 月額利用料の25%をクレジット
- 稼働率95.0%未満: 月額利用料の50%をクレジット

サービスクレジットの申請は、障害発生月の翌月末までにサポート窓口へご連絡ください。

## ストレージ

Enterpriseプランでは、テナントあたり500GBのストレージ容量が提供されます。Standardプランの100GBと比較して5倍の容量です。ストレージはドキュメント、添付ファイル、バックアップデータに使用されます。容量の80%に達した時点で管理者にメール通知が送信されます。追加ストレージは100GB単位で購入可能です。

## APIレート制限

EnterpriseプランのAPIレート制限は1,000リクエスト/秒です。Standardプランの100リクエスト/秒と比較して10倍のスループットに対応しています。レート制限を超過した場合、HTTPステータスコード429（Too Many Requests）が返却されます。APIの利用状況は管理画面の「API設定」→「使用状況」から確認できます。

## SSO/SAML対応

SAML 2.0によるシングルサインオン（SSO）はEnterprise限定の機能です。Microsoft Entra ID、Okta、Google Workspaceなどの主要なIdP（Identity Provider）との連携に対応しています。SAML認証を有効化することで、企業の既存の認証基盤を活用したセキュアなログインが実現できます。設定方法の詳細は「SAML認証設定ガイド」を参照してください。

## 優先サポート

Enterpriseプランでは、サポートリクエストへの初回応答時間を4時間以内に保証しています。Standardプランの24時間と比較して、迅速な対応を受けることができます。優先サポートは平日9:00〜18:00（日本時間）に適用されます。緊急度「Critical」の問い合わせについては、営業時間外でもPagerDuty経由で対応チームに通知されます。

サポートへのお問い合わせは、SampleConnect管理画面の「サポート」→「新規リクエスト」から送信するか、enterprise-support@sampleconnect.example.co.jpへメールでご連絡ください。
