# プラン別機能比較

## 概要

SampleConnect Platformでは、組織の規模や要件に応じてFree、Standard、Enterpriseの3つのプランを提供しています。本ドキュメントでは、各プランの機能と制限を比較形式で説明します。

## 機能比較表

| 機能 | Free | Standard | Enterprise |
|---|---|---|---|
| ユーザー数上限 | 5名 | 100名 | 無制限 |
| ストレージ容量 | 5GB | 100GB | 500GB |
| APIレート制限 | 10 req/sec | 100 req/sec | 1,000 req/sec |
| 監査ログ保持期間 | 30日 | 90日 | 2年間 |
| SSO/SAML認証 | - | - | 対応 |
| SLA（稼働率保証） | - | 99.9% | 99.95% |
| サポート応答時間 | 72時間 | 24時間 | 4時間 |
| カスタムロール | - | 5個まで | 無制限 |
| IPアドレス制限 | - | - | 対応 |
| CloudWatch Logsエクスポート | - | - | 対応 |
| S3エクスポート | - | - | 対応 |
| 専任カスタマーサクセス | - | - | 対応 |

## 各プランの詳細

### Freeプラン

Freeプランは、SampleConnect Platformの基本機能を無料で利用できるプランです。小規模チームや評価目的での利用を想定しています。ユーザー数は5名まで、ストレージは5GBまでの制限があります。監査ログは直近30日分のみ確認可能です。サポートはメールのみで、応答時間の保証はありません（目安として72時間以内）。

### Standardプラン

Standardプランは、中規模組織向けのプランです。最大100名までのユーザーを登録でき、100GBのストレージが利用できます。APIレート制限は100リクエスト/秒で、一般的な業務利用には十分な容量です。監査ログは90日間保持されます。99.9%のSLAが保証され、サポートへの応答時間は24時間以内です。カスタムロールは5個まで作成可能です。

### Enterpriseプラン

Enterpriseプランは、大規模組織やセキュリティ要件の厳しい組織向けの最上位プランです。ユーザー数は無制限で、テナントあたり500GBのストレージが提供されます。SAML 2.0によるSSO対応、IPアドレス制限、2年間の監査ログ保持など、高度なセキュリティ機能を備えています。99.95%のSLAと4時間以内のサポート応答を保証します。CloudWatch LogsおよびS3への監査ログエクスポートにも対応しており、既存の監視基盤やコンプライアンス基盤との統合が可能です。各機能の詳細は「Enterpriseプラン機能ガイド」を参照してください。

## よくある質問

### プランの変更はいつでもできますか

はい、上位プランへのアップグレードはいつでも可能です。SampleConnect管理画面の「組織設定」→「プラン・請求」からアップグレード手続きを行ってください。アップグレードは即時反映されます。日割り計算により、アップグレード日から月末までの差額が請求されます。

下位プランへのダウングレードは、現在の契約期間の終了時に適用されます。ダウングレードの際は、移行先プランの制限（ユーザー数、ストレージ容量など）を事前に確認してください。制限を超過している場合は、ダウングレード前に調整が必要です。

### Enterpriseプランの見積もりがほしい

Enterpriseプランは、組織の規模や要件に応じた個別見積もりとなります。営業担当（sales@sampleconnect.example.co.jp）までお問い合わせください。導入前のPoC（概念実証）環境の提供も可能です。

### トライアル期間はありますか

Enterpriseプランには30日間の無料トライアルがあります。トライアル期間中はすべてのEnterprise機能を利用できます。トライアルの申し込みはSampleConnect管理画面の「プラン・請求」→「Enterpriseトライアルを開始」から行ってください。トライアル終了後、契約手続きを行わない場合は自動的にFreeプランに移行します。

### 複数のテナントを一括管理できますか

Enterpriseプランでは、マルチテナント管理機能を利用できます。親テナントから子テナントの設定やユーザーを一元管理でき、グループ企業での利用に適しています。マルチテナント管理の設定方法は、営業担当までお問い合わせください。
