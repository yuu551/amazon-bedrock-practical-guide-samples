# API認証・監査ログ管理ガイド

## 概要

本ガイドでは、SampleConnect PlatformにおけるAPI認証の設定方法と、監査ログの管理・エクスポート手順を説明します。対象読者はSampleConnect管理画面で「組織管理者」または「IT管理者」ロールを持つ管理者です。

## API認証

### APIキーの発行と管理

SampleConnect PlatformのAPIを利用するには、APIキーまたはOAuth 2.0トークンによる認証が必要です。

APIキーの発行は、SampleConnect管理画面の「API設定」→「APIキー管理」から行います。「新しいAPIキーを作成」をクリックし、以下の情報を入力してください。

- **キー名**: 用途がわかる名前（例: 「社内システム連携用」）
- **権限スコープ**: read、write、adminのいずれかを選択
- **有効期限**: 30日、90日、1年、無期限から選択
- **IPアドレス制限**: APIキーの利用を許可するIPアドレスまたはCIDR（任意）

作成されたAPIキーは一度だけ表示されます。安全な場所に保管してください。紛失した場合は再発行が必要です。APIキーの無効化や削除は「APIキー管理」画面からいつでも実行できます。

### OAuth 2.0クライアント資格情報フロー

サーバー間連携など、ユーザーの介在なしにAPIを利用する場合は、OAuth 2.0のクライアント資格情報フロー（Client Credentials Flow）を使用してください。

1. SampleConnect管理画面の「API設定」→「OAuthクライアント」から新しいクライアントを作成します。
2. クライアントIDとクライアントシークレットが発行されます。
3. トークンエンドポイント（`https://auth.sampleconnect.example.co.jp/oauth/token`）にPOSTリクエストを送信し、アクセストークンを取得します。

```
POST /oauth/token
Content-Type: application/x-www-form-urlencoded

grant_type=client_credentials
&client_id={クライアントID}
&client_secret={クライアントシークレット}
&scope=read write
```

取得したアクセストークンは、APIリクエストのAuthorizationヘッダーに`Bearer {トークン}`の形式で指定してください。トークンの有効期限は1時間です。

## 監査ログ

### 監査ログの確認方法

監査ログは、SampleConnect管理画面の「セキュリティ」→「監査ログ」から確認できます。画面上部のフィルタ機能を使って、以下の条件で絞り込みが可能です。

- **期間**: 開始日と終了日を指定
- **ユーザー**: 特定のユーザーの操作に絞り込み
- **操作種別**: 認証、権限変更、データ操作、設定変更から選択
- **結果**: 成功、失敗、拒否から選択

フィルタ結果はCSV形式でダウンロードできます。

### 監査ログに記録されるイベント種別

監査ログには以下のカテゴリのイベントが記録されます。

**認証イベント**
- ログイン成功・失敗
- SAML認証によるSSO
- MFA認証の成功・失敗
- パスワード変更
- セッションの開始・終了

**権限変更イベント**
- ユーザーの作成・削除・無効化
- ロールの割り当て・変更
- APIキーの作成・無効化・削除
- OAuthクライアントの作成・削除

**データ操作イベント**
- ドキュメントの作成・更新・削除
- ファイルのアップロード・ダウンロード
- データのエクスポート

**設定変更イベント**
- 組織設定の変更
- セキュリティ設定の変更（SSO、IPアドレス制限など）
- プラン・請求設定の変更

### 監査ログの保持期間

監査ログの保持期間はプランによって異なります。

- **Enterpriseプラン**: 2年間
- **Standardプラン**: 90日間
- **Freeプラン**: 30日間

保持期間を過ぎた監査ログは自動的に削除されます。保持期間を超えてログを保管する必要がある場合は、CloudWatch LogsまたはS3へのエクスポートを設定してください。

### CloudWatch Logsへのエクスポート設定

監査ログをAmazon CloudWatch Logsにリアルタイムでエクスポートする手順は以下のとおりです。本機能はEnterpriseプラン限定です。

1. AWSマネジメントコンソールでCloudWatch Logsのロググループを作成します。ロググループ名の推奨は`/sampleconnect/audit-logs/{テナントID}`です。
2. SampleConnectがログを書き込むためのIAMロールを作成します。信頼ポリシーでSampleConnectのAWSアカウント（`123456789012`）からのAssumeRoleを許可し、`logs:CreateLogStream`と`logs:PutLogEvents`の権限を付与してください。
3. SampleConnect管理画面の「セキュリティ」→「監査ログ」→「エクスポート設定」を開きます。
4. 「CloudWatch Logs」タブを選択し、以下の情報を入力します。
   - ロググループARN
   - IAMロールARN
   - リージョン
5. 「接続テスト」をクリックし、ログの書き込みが成功することを確認します。
6. 「エクスポートを有効化」をクリックして設定を保存します。

エクスポートが有効化されると、監査ログはリアルタイムでCloudWatch Logsに送信されます。CloudWatch Logs Insightsを使ったクエリ分析や、CloudWatchアラームによる異常検知が可能になります。

### S3バケットへの長期保管設定

2026年4月のアップデートで追加された機能です。監査ログをAmazon S3バケットに日次で保管する手順は以下のとおりです。本機能はEnterpriseプラン限定です。

1. AWSマネジメントコンソールでS3バケットを作成します。バケット名の推奨は`sampleconnect-audit-logs-{テナントID}`です。バケットのバージョニングとサーバーサイド暗号化（SSE-S3またはSSE-KMS）を有効化してください。
2. SampleConnectがオブジェクトを書き込むためのIAMロールを作成します。`s3:PutObject`と`s3:GetBucketLocation`の権限を付与してください。
3. SampleConnect管理画面の「セキュリティ」→「監査ログ」→「エクスポート設定」を開きます。
4. 「S3」タブを選択し、以下の情報を入力します。
   - S3バケットARN
   - プレフィックス（例: `audit-logs/`）
   - IAMロールARN
5. 「接続テスト」をクリックし、テストオブジェクトの書き込みが成功することを確認します。
6. 「エクスポートを有効化」をクリックして設定を保存します。

S3エクスポートは毎日AM 3:00（JST）に前日分の監査ログをJSON Lines形式で出力します。ファイルパスの形式は`{プレフィックス}{年}/{月}/{日}/audit-log-{テナントID}-{日付}.jsonl.gz`です。S3ライフサイクルポリシーを設定すれば、Glacierへの自動アーカイブによるコスト最適化も可能です。
