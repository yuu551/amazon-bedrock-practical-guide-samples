# SampleConnect Platform 監査ログ保存ポリシー（2025年4月適用版）

本ポリシーは、SampleConnect Platformで生成される監査ログの保持期間、エクスポート可否、削除条件を定めます。本版は2025年4月1日以降の利用月に適用され、2026年版に置き換わるまで有効です。

## 対象ログ

SampleConnect管理コンソールへのログイン、APIキーの発行・失効、SSO設定の変更、IPアドレス制限の更新、Enterprise機能の有効化を含む、テナント内の構成変更を伴うすべての操作を対象とします。エンドユーザーの読み取りリクエスト（参照系API）は対象外です。

## プラン別の保持期間

| プラン | 保持期間 | エクスポート |
|---|---|---|
| Free | 7日 | 不可（コンソール閲覧のみ） |
| Standard | 30日 | CSV/JSON Linesエクスポート（手動のみ） |
| Enterprise | 365日 | CSV/JSON Lines、Amazon S3連携 |

## エクスポートと長期保管

Enterpriseプランは、Amazon S3連携によりニアリアルタイムで監査ログを取り出せます。お客様側で長期保管が必要な場合は、S3バケット上での保存ポリシーをお客様が定めることになります。
