# SampleConnect Platform 監査ログ保存ポリシー（2026年4月適用版）

本ポリシーは、SampleConnect Platformで生成される監査ログの保持期間、エクスポート可否、削除条件を定めます。本版は2026年4月1日以降の利用月に適用され、前版を置き換えます。

## 対象ログ

SampleConnect管理コンソールへのログイン、APIキーの発行・失効、SSO設定の変更、IPアドレス制限の更新、Enterprise機能の有効化に加え、本版から、参照系APIのうちテナント横断で重要となる読み取り操作（監査ログのエクスポート、データ所在地ポリシーの参照など）も対象に追加されます。

## プラン別の保持期間

| プラン | 保持期間 | エクスポート |
|---|---|---|
| Free | 7日 | 不可（コンソール閲覧のみ） |
| Standard | 90日 | CSV/JSON Linesエクスポート、Amazon S3連携、Amazon CloudWatch Logs連携 |
| Enterprise | 730日（24ヶ月） | CSV/JSON Lines、Amazon S3連携、Amazon CloudWatch Logs連携、Amazon Kinesis Data Firehose連携 |

## エクスポートと長期保管

EnterpriseプランはAmazon Kinesis Data Firehose連携が追加され、SIEMへのニアリアルタイム取り込みが容易になります。Standardプランも、本版からCloudWatch Logs連携が標準提供範囲に含まれます。730日を超える長期保管は、Amazon S3連携を用いた顧客側の保管ポリシーで実現してください。

## 改訂履歴

- 2026年4月1日 改訂。Enterpriseの保持期間を365日から730日へ延長、Standardの保持期間を30日から90日へ延長、CloudWatch Logs連携をStandardへ拡大、Kinesis Data Firehose連携をEnterpriseに追加。
