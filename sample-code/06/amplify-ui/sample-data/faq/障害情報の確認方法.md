# 障害情報の確認方法

質問: SampleConnectで障害が起きているか確認する方法は何ですか。

回答: SampleConnect Platformの稼働状況は、3つの経路で確認できます。1つ目は公開ステータスページ（status.sampleconnect.example.com）で、障害発生中・調査中・復旧済みの状態と、影響範囲・更新履歴を時系列で確認できます。2つ目はSampleConnect管理コンソールの「お知らせ」セクションで、契約テナントに影響する事象のみが表示されます。3つ目はサポート窓口で、ステータスページ未掲載の小規模事象や、テナント単位の状況確認に対応します。サポート担当者の社内一次対応手順はFAQには含めず、「障害一次対応手順」マニュアルを参照してください。

補足: 既知障害かどうかの判別、影響範囲の特定、エスカレーション経路は「障害一次対応手順」「エスカレーション手順」を参照してください。
