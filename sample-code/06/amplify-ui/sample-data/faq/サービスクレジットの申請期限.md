# サービスクレジットの申請期限

質問: サービスクレジットの申請期限はいつですか。

回答: サービスクレジットの申請期限は、対象障害が発生した月の翌月末日（23:59 JST）までです。期限を過ぎた申請は受け付けられません。申請は、SampleConnectサポートポータルの「請求」→「サービスクレジット申請」フォーム、もしくはサポート窓口へのメールで受け付けます。申請には、対象障害の発生日時、影響範囲、業務影響、対象テナントID、対象月の請求書番号を添えてください。申請受領後、5営業日以内にBilling部門が判定結果を返答します。

補足: 適用条件と算定方法は「SLAポリシー2026年版」、請求への反映タイミングは「課金請求ポリシー2026年版」を参照してください。
