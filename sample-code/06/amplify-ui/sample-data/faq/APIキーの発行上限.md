# APIキーの発行上限

質問: APIキーは何本まで発行できますか。

回答: APIキーの同時有効本数は、Standardプランでは5本、Enterpriseプランでは50本までです。Freeプランでは1本のみ発行できます。発行・失効の操作は、SampleConnect管理コンソールの「API設定」→「APIキー」から行います。失効済みのキーは本数にカウントされません。Enterpriseプランで50本を超えて発行したい場合は、サポート窓口経由で上限緩和を申請してください。緩和は契約条件と利用用途を確認したうえで個別に判断します。

補足: APIキーのスコープ設計やローテーション運用は「API認証・監査ログ管理ガイド」を参照してください。誤って公開した場合の対応は「APIキー誤公開時の対応」を参照してください。
