# 監査ログのエクスポート方法

質問: 監査ログはエクスポートできますか。

回答: 監査ログのエクスポートは、StandardプランとEnterpriseプランで利用できます。SampleConnect管理コンソールの「セキュリティ」→「監査ログ」→「エクスポート」から、CSVまたはJSON Lines形式でダウンロードできます。日次の自動エクスポートと、Amazon S3バケットへのストリーム連携にも対応しており、Enterpriseプランではさらに、Amazon CloudWatch LogsまたはAmazon Kinesis Data Firehose宛にニアリアルタイムで転送できます。Freeプランでは、コンソール上での閲覧のみ可能です。

補足: 連携先のエンドポイント設定や、SIEM側での取り込みフォーマットは「API認証・監査ログ管理ガイド」、申請が必要な保持期間延長や長期保管設計は「監査ログ保存ポリシー」を参照してください。
