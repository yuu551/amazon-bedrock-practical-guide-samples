# 障害発生時の顧客向け初回案内

質問: 障害発生時、顧客には最初に何を案内しますか。

回答: 障害の問い合わせを受け付けたら、最初に「お問い合わせを受け付けたこと」「現在ステータスページ上で既知事象として扱われているかを確認中であること」「次回の状況更新の予定時刻」の3点を返します。回避策の有無は、ステータスページまたは社内Confluenceに記載がある場合のみ、その旨を伝えます。情報が確定していない段階で原因や復旧見込みを伝えないでください。返答テンプレートは、SampleConnectサポートポータルの「定型文」→「障害初回案内」に登録されています。

補足: 一次対応の判断基準やエスカレーション経路は「障害一次対応手順」、お客様向けポストモーテム作成手順は「インシデント報告手順」を参照してください。
