# Enterpriseプランのサポート応答時間

質問: Enterpriseプランのサポート応答時間は何時間ですか。

回答: Enterpriseプランの初回応答SLAは、優先度Critical（サービス全停止または重大なセキュリティ影響）が1時間以内、Highが4時間以内、Mediumが1営業日以内、Lowが3営業日以内です。Critical優先度に限り、24時間365日の時間外受付に対応します。一次受付窓口はSampleConnectサポートポータルですが、契約ごとに専用Slackコネクトチャネルを開設します。テクニカルアカウントマネージャー（TAM）が割り当てられている場合は、TAM宛てに直接エスカレーションすることも可能です。

補足: 優先度の判定基準と各プランの差分は「プラン別機能比較」、SLA違反時の補償条件は「SLAポリシー2026年版」を参照してください。
