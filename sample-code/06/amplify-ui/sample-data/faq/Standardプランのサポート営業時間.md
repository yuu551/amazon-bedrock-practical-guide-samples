# Standardプランのサポート営業時間

質問: Standardプランのサポート窓口は何時から何時までですか。

回答: Standardプランのサポート窓口は、平日（月曜〜金曜、日本の祝祭日と年末年始を除く）の9:00〜18:00 JSTで対応しています。Freeプランでは、人によるサポート窓口は提供しておらず、ヘルプセンターのドキュメントとコミュニティフォーラムでの相互支援に限られます。営業時間外に発生した問い合わせは翌営業日に順次対応しますが、ステータスページ上の重大障害は24時間365日で更新されます。

補足: 各プランの初回応答SLAやエスカレーション経路は「プラン別機能比較」、Enterpriseプランの時間外サポートは「Enterpriseプランのサポート応答時間」を参照してください。
