# プラン変更の反映タイミング

質問: プラン変更はいつ反映されますか。

回答: プラン変更の反映タイミングはプラン区分によって異なります。Free→Standard、Standard内のシート数変更は、SampleConnect管理コンソールから即時申し込めて15分以内に反映されます。Standard→Enterpriseおよびその逆は、契約条件と請求の見直しが必要なため、営業窓口経由でおよそ2週間（最短5営業日）かかります。プラン変更月の請求は日割りで調整され、サービスクレジットの計算もプラン変更日を境に分けて算定されます。

補足: 請求書反映の詳細は「課金請求ポリシー2026年版」、Enterprise契約手続きの流れは「Enterprise契約申し込みフロー」を参照してください。
